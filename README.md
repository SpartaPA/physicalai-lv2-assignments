## 오늘 수업: 세팅과 문제 1

[SSH·라즈베리파이·OpenCR 실습 순서](모듈1_임베디드제어기초/오늘_과제1_SSH_라즈베리파이_OpenCR.md)를 따릅니다. Ubuntu Server 22.04의 라즈베리파이에서 업로드·시리얼 수신·로그 저장을 모두 수행합니다. PC는 SSH 접속에만 사용합니다. 위 20장 PPT는 전체 4문제용이며 오늘은 문제 1까지 진행합니다.

## 모듈 1 개정 기준

이론 1강+실습 5강, 이론 2강+실습 6강, 이론 3강+실습 7강, 이론 4강+실습 8강을 연결합니다. 준비된 환경에서 약 90분, 4문제 각 25점이며 실험 A·B 두 번의 기록을 재사용합니다. 새 PID 구현이나 micro-ROS 설치는 요구하지 않습니다.

모듈 1은 개정 과제 기준을 우선합니다. 나머지 모듈은 전체 발제문서의 기준을 따릅니다. 판서가이드와 강사용 해설은 이 학생 공개 레포에 포함하지 않습니다.

## 제출

학생별 제출 레포는 Lv.1과 같은 방식으로 `physicalai-lv2-<이름>`을 사용합니다. 제출일과 제출 경로는 운영 공지를 따릅니다. 모듈 1 상세 제출 형식은 [과제 안내](과제_안내.md)를 확인하세요.
