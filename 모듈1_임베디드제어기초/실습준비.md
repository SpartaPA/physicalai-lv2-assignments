# OpenCR·다이나믹셀 실습 준비

**오늘 수업은 [라즈베리파이 Ubuntu Server 22.04·SSH 전용 절차](오늘_과제1_SSH_라즈베리파이_OpenCR.md)를 우선합니다. 아래 Arduino IDE 안내는 기존 일반 환경 참고이며 오늘 학생 실습에서는 사용하지 않습니다.**

이 준비 작업은 90분 과제 시작 전에 진행자가 완료·확인합니다.

1. OpenCR 1.0과 다이나믹셀 모델, 통신 케이블(TTL/RS-485), 전원 정격을 확인합니다. USB 연결만으로 모터 전원이 준비되었다고 판단하지 않습니다.
2. 제공 P 예제 기준은 XM430-W350(모델 번호 1020), Protocol 2.0, ID 12, 1 Mbps입니다. 실제 장비 설정과 일치시킵니다. 다른 모델은 진행자가 검증한 호환 예제를 준비합니다. 모델 검사를 제거하지 않습니다.
3. Arduino IDE의 OpenCR 보드 지원과 Dynamixel2Arduino 라이브러리를 준비하고, [P 예제](examples/opencr_position_p/opencr_position_p.ino)를 엽니다. 보드와 포트를 선택해 업로드합니다.
4. 시리얼 모니터는 115200 bps, 새줄(Newline)로 설정하고 READY를 확인합니다. FAULT가 나오면 반복 실행하지 말고 진행자에게 점검을 요청합니다.
5. 모터를 고정하고 회전 범위를 비웁니다. 진행자가 확인한 작은 상대각과 낮은 속도 상한을 사용합니다. +30도·15도/초는 설정 예시이며 모든 장비의 안전을 보장하는 값이 아닙니다.
6. `x` 정지와 전원 차단 위치를 확인합니다. `x`는 소프트웨어 정지이며 통신 실패 시 동작을 보장하지 않습니다. 토크가 켜진 축을 손으로 되돌리지 않습니다. 매 실행마다 현재 위치가 새 원점이므로 다음 실행의 이동 여유를 확인합니다.

OpenCR이 위치 오차로 속도 명령을 계산하고 다이나믹셀에 보냅니다. 다이나믹셀 내부 속도 제어도 동작합니다. GPIO PWM이나 RC 서보 펄스로 위치를 명령하는 실습과 구분합니다.
